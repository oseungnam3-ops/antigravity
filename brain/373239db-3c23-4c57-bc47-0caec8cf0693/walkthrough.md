## 2. 권한별 테스트 및 조작 방법 (개발용 스위처)

화면 상단에 있는 **개발용 권한 변경기**를 사용하면 실시간으로 성도의 권한을 스위칭하여 각 역할별 화면을 즉시 확인해볼 수 있습니다.

### ① 가입 대기자 (Role: `pending`)
* **로그인 시**: 하단 말씀묵상, 성경공부 등을 클릭하면 **"관리자 승인 대기 중"** 안내 화면이 나타나며 콘텐츠 접근이 철저히 차단됩니다.
* **테스트 방법**: 개발용 권한 변경기에서 `1. 가입대기자` 버튼을 클릭하면 즉시 차단 화면이 노출됩니다.

### ② 일반 성도 (Role: `member`)
* **홈 화면**: 오늘의 말씀 카드, 내 진도 요약 그래프, 최신 주일 설교 영상(유튜브 링크 연동), 교회 공지사항 제공.
* **말씀묵상**: 본문 및 오늘의 기도문 조회, 묵상/적용 질문 답변 및 기도제목 작성 후 제출 (제출 완료 시 내가 쓴 답변과 성도들의 눔 목록 실시간 조회 가능).
* **성경공부**: 새가족반 등 과정 정보 및 1~4강 목록 제공. 각 강의 시청, 핵심 요약 확인, 동영상 학습 완료 버튼 터치, 과제 작성 및 제출 가능.
* **설교영상**: 주일 설교 영상 시청 및 설교 요약/적용 질문 제공.
* **내 정보**: 내 전체 진도율 및 제출한 과제 목록 확인 가능.

### ③ 리더 / 교사 (Role: `leader`)
* **내 정보(교사 대시보드)**: 
  - 담당 교구의 성도 수 및 피드백 대기 과제 건수 표시.
  - 성도가 제출한 과제 카드를 터치하여 **댓글 피드백 및 채점(격려 메시지)** 등록 가능.
  - 담당 성도들의 c1 과정(새가족반) 수강 진도율 목록 실시간 확인.

### ④ 관리자 (Role: `admin` - 담임목사 등)
* **내 정보(관리자 대시보드)**:
  - **가입승인 탭**: 가입 신청을 넣은 대기자들의 상세 프로필 확인 후 **'가입승인'** 또는 **'가입거절(반려)'** 처리. 승인 시 해당 성도는 즉시 일반 성도 권한으로 승급되어 콘텐츠 열람 가능.
  - **권한관리 탭**: 이름/교구로 회원을 실시간 검색하고 권한을 강제로 변경 가능.
  - **콘텐츠등록 탭**: 말씀 묵상 정보(날짜, 성경본문, 제목, 질문, 기도문) 또는 성경공부 신규 강의(유튜브 링크, 핵심 요약, 과제 질문 등)를 폼을 통해 간편하게 추가 가능. 추가된 데이터는 Mock DB에 반영되어 성도 탭에 실시간 적용됩니다.
  - **학습통계 탭**: 개설된 교육 과정별로 현재 수강 중인 성도 인원수와 평균 학습 진도율 통계 확인.

## 3. 검증 결과

1. **승인 차단 검증**: 가입 대기자(pending) 권한으로 메뉴 접근 시 모든 콘텐츠 차단 및 안내 화면이 완벽하게 렌더링됨을 확인했습니다.
2. **진도율 실시간 반영**: 일반 성도로 강의 완료 버튼을 누르거나 과제를 제출했을 때 '내 정보' 및 '홈 화면'의 학습 진행률 그래프가 실시간으로 변경되어 세션 상태가 잘 반영됨을 확인했습니다.
3. **교사 피드백 피드백**: 교사 권한으로 성도의 제출물에 피드백을 등록하면, 다시 해당 성도 계정으로 들어갔을 때 교사의 격려 메시지가 강의 하단과 내 정보 탭에 온전히 표시됨을 확인했습니다.
4. **큰 글씨 모드 적용**: 우측 상단 토글 클릭 시 `.large-text` 클래스가 주입되어 시력이 좋지 않은 어르신들도 손쉽게 읽을 수 있도록 UI 배치가 확장됨을 검증했습니다.
